# Fight Promo Bot

Бот публікує анонс бою у вашому Telegram-каналі з таймером зворотного
відліку, який сам оновлюється.

## 1. Створіть бота

1. Напишіть [@BotFather](https://t.me/BotFather) → `/newbot`
2. Скопіюйте виданий токен

## 2. Додайте бота в канал

1. Відкрийте налаштування вашого каналу → Адміністратори → Додати адміністратора
2. Додайте вашого бота, дайте право "Публікувати повідомлення"
3. Якщо канал приватний — використовуйте його числовий ID (напр. `-1001234567890`)
   замість `@username`. Дізнатись ID можна, переславши будь-яке повідомлення з
   каналу боту [@userinfobot](https://t.me/userinfobot).

## 3. Дізнайтесь свій user id

Напишіть [@userinfobot](https://t.me/userinfobot) — він покаже ваш `id`.
Його треба вписати в `ADMIN_IDS`, щоб тільки ви могли постити анонси.

## 4. Налаштування

Скопіюйте `.env.example` у `.env` і заповніть:

```
BOT_TOKEN=токен_від_botfather
CHANNEL_ID=@назва_каналу_або_id
ADMIN_IDS=ваш_user_id
```

## 5. Запуск

```bash
pip install -r requirements.txt
python bot.py
```

Бот має працювати безперервно, тому для постійної роботи його варто
розмістити на хостингу (не вимикати свій комп'ютер — не варіант для 24/7):

- **Railway.app** — найпростіше: завантажте ці файли як репозиторій на GitHub,
  підключіть до Railway, додайте змінні середовища (BOT_TOKEN, CHANNEL_ID,
  ADMIN_IDS) у налаштуваннях проєкту, Railway сам запустить `python bot.py`.
- **PythonAnywhere** — безкоштовний план, підтримує постійні процеси (always-on task).
- **Власний VPS** — запустити через `systemd` або `screen`/`tmux`, щоб бот жив
  після закриття терміналу.

## 6. Використання

Напишіть боту в особисті повідомлення (не в канал!) фото афіші з підписом:

```
Михайло Діденко vs Данило Коваленко
21.11.2026 20:00
Львів, СК «Грація»
```

- 1-й рядок — назва бою (будь-який текст)
- 2-й рядок — дата і час у форматі ДД.ММ.РРРР ГГ:ХХ
- 3-й рядок — місце (можна пропустити)

Бот одразу опублікує пост у каналі та сам редагуватиме таймер:
- раз на ~3 години, якщо до бою більше доби
- раз на 30 хв в останню добу
- раз на 5 хв в останні 2 години

Коли час бою настає, підпис змінюється на "🔴 Бій почався!" і оновлення
зупиняються.

Дані про опубліковані анонси зберігаються у файлі `fights.json` поруч зі
скриптом — бот переживає перезапуск і продовжує оновлювати всі активні пости.
